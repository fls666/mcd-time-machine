# 麦麦时光机（McD Time Machine）

把用户的麦当劳历史订单，变成一份有情绪价值的年度回忆与口味画像。

## 前置条件

1. 用户已在 https://open.mcd.cn/mcp 申请到 MCP Token；
2. 已在 WorkBuddy 中把 `mcd-mcp` 配置为自定义连接器并启用（配置见 `mcp-config.example.json`，
   `Authorization` 填 `Bearer <Token>`）。

## 执行流程

### 第零步：先确认能拿到数据

若用户尚未采集过，先运行 `mcdtm doctor` 诊断连通性与 `order-list` 的真实入参 schema / 返回结构。
解析不到订单时，**不要凭猜测编造解析规则**。

> **隐私红线（不可违反）**
> `mcdtm-output/doctor.json`、`raw/` 与 `orders.normalized.json` 含真实订单号、金额、门店等个人信息，
> **禁止**直接粘贴给用户、复制到对话里、或上传到任何公开渠道（含 Issue、讨论区、截图）。
> 需要对外反馈结构时，只能运行 `mcdtm share` 生成脱敏后的 `share.json`，
> 并**提醒用户自己先通读一遍**再决定是否分享——脱敏无法保证覆盖所有未知字段。
> 同理：`story.html` 内嵌了完整订单统计结果，**对外分享只能发故事页里导出的 `share-card.png`**，
> 不要直接转发 HTML 文件（`report.html` 亦同）。

### 第一步：拉数据

调用 `mcd-mcp` 的 `order-list` 获取历史订单（CLI 会自动翻页并去重）。
若返回为空或结构异常，如实告诉用户，不要编造订单内容。

可选增强（失败就跳过，不要卡住）：
- `query-meals` —— 真实菜单，用于推荐
- `list-nutrition-foods` —— 热量参考
- `query-my-coupons` / `query-my-account` / `campaign-calendar` —— 券、积分、活动上下文

### 第二步：本地分析

按以下维度统计，**只用真实数据，不要虚构订单**：

- 数字总览：订单数、累计消费、平均客单价、单品总数、月均消费、最长连续打卡
- 口味画像：嗜辣星人 / 甜食主义 / 汉堡原教旨 / 薯条依赖症 / 咖啡续命 / 早起干饭人 / 夜宵常客 / 性价比猎手
- 品类偏好：汉堡 / 小食 / 甜品 / 饮料 / 早餐 / 沙拉 的件数与占比
- 时间切片：时段分布（清晨/早餐/午餐/下午茶/晚餐/夜宵/深夜）与一周七天节奏
- 消费趋势：逐月订单数与消费额
- 年度回忆：记录中的第一单、最豪华的一单、最常光顾的月份、常去门店、深夜食堂、最长连续打卡
- 黄金搭档：同单共现次数最高的组合

### 第三步：给建议

结合 `query-meals` 的真实菜单，挑出用户**还没点过**的单品，优先命中其偏好品类，
也保留 1–2 个跨品类的「破圈」推荐。每条必须给出一句具体理由（引用数据，不要空话）。

### 第四步：出报告

优先调用本项目的 CLI 生成标准报告：

```bash
mcdtm fetch      # 拉数据
mcdtm analyze    # 生成 report.md / report.html / story.html / profile.json
mcdtm story      # 只重刷沉浸式故事页（不联网、不重算）
```

若用户只想看结论，可直接在对话里输出要点摘要，并提示 HTML 报告可截图分享。

没有 Token 时，用 `mcdtm demo` 生成虚构示例数据演示效果——**必须明确说明这是示例数据**。

## 约束

- **如实说明统计范围**：必须告知用户数据来自真实 MCP 还是示例数据、统计区间覆盖到哪一天、
  有多少单缺少金额或明细。宁可让报告显得不完整，也不能让它显得比实际更完整。
- **金额口径要分清**：「实际支付金额」与「按单价×数量估算的商品金额」不能混为一谈。
  有实付金额时以实付为准；展示估算值必须标注「估算」，并说明未包含优惠券、配送费与退款。
- 只读取历史数据，**绝不调用** `create-order`、`auto-bind-coupons`、`draw-lottery` 等会产生实际行为的工具。
- 不外发用户订单数据，不要求用户提供 Token 明文，只提示设置环境变量 `MCD_MCP_TOKEN`。
- 报告不构成营养或医疗建议；餐品信息、价格以麦当劳官方渠道实时结果为准。
- 涉及金额一律用 `¥` 并保留两位小数。
